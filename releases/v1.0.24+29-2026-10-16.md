# TaybGo Seller 1.0.24+29

Release date: 16 October 2026.

- Create Rescue Deals for discounted menu items, with stock, schedules and optional customer limits.
- Monitor available, reserved and sold quantities; safely adjust stock, pause or resume deals, and archive finished offers.
- Preserve Rescue Deal identities and saved prices in order details and order edits, including regular and rescue lines for the same item.
- Restrained, responsive deal screens with Arabic/English support, light/dark themes, and release notes in all 11 supported languages.

## Production packaging

Production API: `https://taybgo.com`. Android application ID and iOS bundle ID: `com.taybgo.seller`. Firebase project: `sellertaybgo`.

iOS uses version 1.0.24, build 29. The Android bundle uses version 1.0.24, version code 4029, above earlier per-ABI APK codes. The in-app release label is 1.0.24+29 on both platforms.

Both release scripts require an ignored private defines file containing `ENV=prod` and `GOOGLE_MAPS_API_KEY`. Reuse the approved production configuration, never commit it, and validate the compiled packages as well as the inputs.

```sh
sh scripts/release/build_aab.sh /private/path/release-defines.json
sh scripts/ios/build_release.sh /private/path/release-defines.json /private/path/ExportOptions.plist
python3 scripts/ios/validate_ipa.py /path/seller.ipa --version 1.0.24 --build 29 --report /path/ipa-validation.json
```
